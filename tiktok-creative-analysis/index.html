One column per loaded file — single days and ranges alike, oldest → newest, never summed. Available = rows minus Not active / Unavailable / Rejected / Excluded / Authorization needed. Outstanding + Performing are subsets of Explored. Hover any day to preview the visible values with their vs-prev moves; card deltas read vs the previous loaded file (green +, red −). Click any legend entry to show or hide that stage. The five cards above are always on; the other 7 stages (Underperforming, Calculating, Rejected, Authorization needed, Unavailable, Excluded, Not active) start hidden and gain a card when their line is switched on — for those a rise is bad news, so their deltas flip (red +, green −). Respects Account / Campaign / Search / Exclude Product Card / Hide inactive; ignores Status / 2nd-status / Type / Insight / Hide Ineligible so the stages stay visible.

General notes

  • Please use the full data file — it is safe to use for checking sales and performance.
  • Two files can show a different video count for the same account (e.g. Dr. Samhan). This is normal: one file also lists old inactive videos with no views and no cost. Your live videos and total sales are the same in both.
  • Account names must match exactly. For example, Dr. Samhan and Dr Samhan are treated as two different accounts.
  • Numbers can shift slightly between downloads because TikTok updates its data.
