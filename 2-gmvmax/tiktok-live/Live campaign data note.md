# TikTok Live Campaign Data (2026-09-18 to 2026-09-20)

**File:** `Live campaign data 2026-09-18 - 2026-09-20.xlsx`

## Description
This workbook contains a single sheet named **`Data`** with 189 rows of TikTok Live campaign performance metrics spanning the date range 2026-09-18 to 2026-09-20. All amounts are in **MYR** (Malaysian Ringgit).

## Columns (18 fields)

| # | Column | Description |
|---|---|---|
| 1 | **Campaign ID** | Unique identifier for each LIVE campaign |
| 2 | **Campaign name** | Campaign name with affiliate/date tags |
| 3 | **Cost** | Total spend for the campaign |
| 4 | **Gross revenue** | Total revenue generated |
| 5 | **ROI** | Return on investment ratio |
| 6 | **SKU orders** | Number of SKU orders |
| 7 | **ROI protection** | Protection status (e.g., "ROI protection eligible") |
| 8 | **Active upgrades** | Count of active upgrades |
| 9 | **Net Cost** | Net cost after adjustments |
|10 | **Cost per order** | Cost per order metric |
|11 | **LIVE views** | Number of live views |
|12 | **Target ROI cost** | Target ROI cost threshold |
|13 | **Base target ROI result** | Base ROI result |
|14 | **Viewer boost cost** | Cost for viewer boost |
|15 | **Creative boost budget** | Creative boost budget allocation |
|16 | **Creative boost cost** | Creative boost actual cost |
|17 | **Current budget** | Remaining/current budget |
|18 | **Currency** | MYR |
